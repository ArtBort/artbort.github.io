Log in

You log in with a GitHub access token. It works like a key that only you have. Without it nobody can change your site, even though this page is public.

How do I get a token?
  1. On github.com, click your profile picture, then Settings.
  2. Scroll to the bottom of the left menu and click Developer settings, then Personal access tokens, then Fine-grained tokens.
  3. Click Generate new token and give it a name, like "Website admin".
  4. Pick an expiry date (for example 90 days). When it expires you just make a new one.
  5. Under Repository access choose Only select repositories and pick your website repository.
  6. Under Permissions, then Repository permissions, set Contents to Read and write.
  7. Click Generate token and copy it. GitHub only shows it once, so paste it here straight away. Menu names can differ a little over time.

Only tick "Keep me logged in" on your own device. If you lose the token or think someone saw it, delete it on GitHub and make a new one.

Your works

Change the name, description and details of each work, then press Save changes. The site updates about a minute later.

Photos upload straight away when you pick them. They do not need the Save button. A work only shows on the site once it has Photo 1.

A new work gets its own folder name. Upload its photos into that folder on GitHub and it appears on the site.
