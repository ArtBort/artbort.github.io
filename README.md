# Photo folders

Every place on the site has its own folder. Put your photos in that folder and name them exactly:

- `1.jpg` is the main photo
- `2.jpg` and `3.jpg` are extra photos (optional)

Use lowercase names. `.jpeg` and `.png` also work. Resize photos to about 1600 pixels wide first so the site loads fast.

To change a photo, upload a new file with the same name. It replaces the old one. If a photo is missing, the site just skips it.

## Page folders (only `1.jpg`)

| Folder | Where it shows |
|---|---|
| `header` | The big photo at the top of the page |
| `portrait` | Your photo next to the intro text |
| `about-streaming` | Optional photo in "Streaming art on the internet" |
| `about-recycled` | Optional photo in "Recycled materials" |
| `about-surrealism` | Optional photo in "Surrealism" |
